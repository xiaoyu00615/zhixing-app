# 01｜项目说明

版本：V1.0  
日期：2026-08-19

## 1. 项目概述

“知行｜个人知识与行动中枢”是一款面向单用户的本地优先个人效率软件。

目标不是做一个单纯 Todo 工具，而是建立一条完整个人信息流：

快速记录  
→ 梳理  
→ 转为任务 / 笔记 / 日记  
→ 执行  
→ 搜索与再次利用

## 2. 核心产品理念

### Capture
任何碎片信息都可以快速记下。

### Connect
任务、笔记、日记、画布节点之间可以建立关系。

### Convert
随手记录可转换为任务、笔记、日记或画布内容。

### Local First
没有网络、账号、云服务时，核心功能仍应正常工作。

## 3. 核心模块

### 首页
负责“看今天”和快速进入下一步。

主要内容：
- 今日概览
- 今日重点任务
- 今日日程
- 最近记录
- 最近笔记
- 最近画布
- 快速记录

首页不承载完整任务表格、完整四象限或完整画布编辑器。

### 任务
包含：
- 列表
- 四象限
- 日历
- 时间线
- 新建任务 Modal
- 任务详情 Drawer
- 标签
- 截止时间
- 紧急度
- 软删除
- 回收站恢复

任务中的“已逾期”是动态计算属性，不作为唯一业务 status。

### 画布
包含：
- 画布列表
- 无限画布编辑器
- Node
- Edge
- 图片节点
- 文字节点
- 链接节点
- 任务节点
- 笔记节点
- 日记节点
- 分组
- Undo / Redo
- 搜索当前画布
- 后续 AI 整理

画布列表页和编辑器必须分离。

### 日记
包含：
- 今日日记
- 日历
- 时间轴
- 标签
- 智能日记夹
- 自动保存
- 关联任务 / 笔记 / 画布

### 笔记
包含：
- 笔记列表
- 文件夹
- 标签
- 收藏
- 富文本编辑
- 图片 / 附件
- 任务 / 画布 / 日记关联

Diary 与 Note 在数据层优先考虑共用 Document 模型，通过 type 区分。

### 搜索
本地搜索：
- Task
- Canvas
- CanvasNode
- Note
- Diary
- Tag
- Attachment metadata

支持分类、标签、日期和状态筛选。

### 标签
标签是跨模块过滤器，不是独立内容孤岛。

### 归档
用于暂时不需要但不希望删除的内容。

### 回收站
承载 Soft Delete 内容，支持恢复、永久删除、批量恢复、清空回收站。

### 数据与存储
支持数据位置查看、数据位置迁移、附件位置管理、本地容量查看、缓存清理、数据导入 / 导出。

### 备份与恢复
支持自动备份、手动备份、备份历史、恢复、恢复前安全快照。

### 设备同步
仅用于同一用户自己的设备，例如 Windows PC ↔ Android Phone，不表示团队协作。

### AI
AI 是嵌入式工具，不做一级主导航。

未来可用于：
- 自动标签
- 总结笔记
- 整理 Canvas
- 提取任务
- 发现内容关系

## 4. 平台关系

### Web
用于快速开发、预览、调试和网页使用。

### Windows Desktop
与 Web 主 UI 基本一致，通过 Tauri 获得本地系统能力。

### Android
后续单独做移动端适配，不允许简单把桌面 UI 等比缩小。

## 5. 数据原则

Native 核心数据使用 SQLite。附件保存在本地文件系统。未来 Web 端使用独立 Web 数据 Adapter。

禁止多个设备直接共享同一个 SQLite 文件作为实时数据库。
